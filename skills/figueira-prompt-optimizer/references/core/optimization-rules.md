# Optimization rules

## Preserve intent
Do not change the user's goal merely to make the prompt look more sophisticated.

## Convert ambiguity into useful structure
Infer safe defaults when possible. Return multiple destination variants when surface differences materially affect the prompt.

## Prefer outcome-first prompting
Structure around objective, relevant context, requirements, constraints, references/assets and acceptance criteria.

Only add step-by-step execution instructions when the destination needs them or the user explicitly requested a procedure.

## Remove filler
Avoid unnecessary role prompts, praise, verbosity and generic statements about expertise.

## Asset fidelity
When reference assets exist, specify whether each controls identity, geometry/product fidelity, composition, style, motion, opening/ending frame or continuity.

Never tell a generator to copy all properties of a reference when only one property is intended.
