# Text modality

For general text tasks, optimize around:
- objective;
- relevant context;
- audience when it changes the result;
- source material or facts that must be used;
- constraints;
- output format;
- quality/acceptance criteria when useful.

Prefer natural, direct instructions. Do not add persona role-play unless the role materially changes domain behavior.

For transformation tasks, preserve meaning and explicitly identify what may change: tone, length, structure, language, level of detail or format.

Do not restate context already persistent in the destination agent unless the task depends on an exception or local override.
