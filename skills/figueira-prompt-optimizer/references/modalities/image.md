# Image modality

## Create
Capture only useful visual variables: subject, scene/environment, composition/framing, viewpoint/angle, lighting, palette, material/texture, style/medium, lens/focus when useful, text inside image when required and aspect ratio when relevant.

Do not blindly fill every variable.

## Edit / image-to-image
Separate:

**Modify**
- exact changes requested.

**Preserve**
- identity;
- pose/composition;
- product geometry;
- logo/text;
- background;
- lighting/style.

Include only preservation constraints that matter.

## Reference use
State whether each reference controls identity, product fidelity, composition, lighting, palette or style.
