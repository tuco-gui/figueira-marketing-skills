# Coding modality

A coding prompt should normally define:
- goal;
- relevant repository/files/components;
- current behavior when important;
- required behavior;
- constraints;
- existing patterns to reuse;
- acceptance criteria;
- validation/tests.

Do not include generic software-engineer role-play.

If the agent can inspect the repository, instruct it to inspect relevant existing code rather than inventing architecture from scratch.
