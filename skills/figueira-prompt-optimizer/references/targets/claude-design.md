# Claude Design adapter

Claude Design is a conversational design surface for editable design work such as prototypes, wireframes/mockups, presentations and one-pagers. Do not treat it as Claude Code or as a generic text-to-image generator.

Recommended structure:
```text
Artifact: [prototype / wireframe / mockup / deck / one-pager / other]
Goal: ...
Audience: ...
Content / hierarchy: ...
Interaction or responsive behavior: ...
Visual direction: ...
Assets / references: ...
Constraints: ...
Handoff / definition of done: ...
```
Omit empty sections.

If a design system is already configured in Claude Design, rely on it rather than re-injecting all brand rules. State only relevant exceptions or task-specific constraints.

For prototypes, describe user flow and states. For decks, describe narrative and slide hierarchy. For one-pagers, prioritize information hierarchy and scannability.
