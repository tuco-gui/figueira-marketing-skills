# Grok Imagine adapter

## Image generation / Image 2.0
Use natural-language visual instructions. Include composition, typography/layout, style and fidelity constraints only when they matter.

## Image editing
Identify the source/reference role and state:
- requested modification;
- properties that must remain stable;
- how additional references should influence the result.

## Video / Video 1.5
For text-to-video, describe the shot, action, camera behavior, pacing and sound when relevant.

For image-to-video, treat the input still as the starting frame. Focus the prompt on:
- motion of subject/environment;
- camera move;
- pacing/temporal development;
- atmosphere/physics;
- sound design/dialogue when requested;
- details that must remain faithful to the source image.

Do not re-describe every visible source-image property.
