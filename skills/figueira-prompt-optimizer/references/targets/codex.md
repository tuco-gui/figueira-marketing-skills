# Codex adapter

Prefer an issue-like task specification:

```text
## Goal
## Relevant context
## Requirements
## Constraints
## Existing implementation/patterns to reuse
## Files or repositories to inspect
## Acceptance criteria
## Validation
```

Omit empty sections. Do not repeat project-wide rules already present in `AGENTS.md` unless the task overrides them. Prefer outcomes and validation over micromanaging the agent's reasoning process.
