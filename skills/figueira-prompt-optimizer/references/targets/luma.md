# Luma Dream Machine adapter

Use natural, descriptive language rather than tag soup.

For image creation, describe the intended result, style, mood, lighting and composition at the level required for control.

For video, emphasize action, camera behavior and temporal evolution. If keyframes or source assets are part of the selected workflow, explain what each frame/asset controls instead of redundantly narrating all visible details.

Keep settings such as aspect ratio, duration or keyframe selection separate from prose when the interface exposes them independently.
