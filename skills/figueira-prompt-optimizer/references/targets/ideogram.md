# Ideogram adapter

Use plain natural language.

Do not inject Midjourney-style prompt weights, coded flags or syntax such as `::`, `--ar`, `--v` or `--style` into the textual prompt. Use the product's UI/settings for controls it exposes separately.

Put the most important visual information early. Describe subject, composition, style, typography and color in ordinary language.

For reference or editing workflows, identify whether the uploaded image controls character, style or editable source content. Preserve exact text strings when typography is a core requirement.
