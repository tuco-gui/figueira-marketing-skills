# OpenAI image adapter

Use clear natural language. A strong prompt is usually concise rather than keyword-stuffed.

Prioritize only details that matter:
- purpose/use of image;
- main subject and action;
- environment;
- visual style/medium;
- composition/framing;
- lighting/materials/color when important;
- exact text/layout requirements when applicable;
- constraints that must remain fixed.

For edits, state the requested change directly and explicitly name critical properties that must remain unchanged.

Do not convert the prompt into diffusion-style tag soup unless the user explicitly requests that format.
