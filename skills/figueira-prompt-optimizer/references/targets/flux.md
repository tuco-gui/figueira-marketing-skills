# FLUX adapter

For FLUX.2, use clear natural language. A useful starting structure is:

`Subject + Action + Style + Context`

Expand with composition, camera/lens, lighting, typography, colors or materials only when they improve control.

## Negative prompting
FLUX.2 does not use a negative-prompt workflow. Rewrite exclusions positively when possible instead of producing a separate negative prompt.

## Editing / references
For single- or multi-reference editing, define the role of each reference and distinguish modifications from properties that must remain stable.

When exact text must appear in an image, preserve the wording exactly and make it explicit that the quoted content is visible text.
