# Midjourney adapter

Prefer short, specific, descriptive prompts over long conversational instructions.

Useful visual dimensions when they matter:
- subject;
- medium;
- environment;
- lighting;
- color;
- mood;
- composition.

Describe what should appear rather than writing long negative instructions. Use dedicated exclusion/parameter syntax only when the active Midjourney surface/version supports it.

## Image references
Treat image prompts/style references/omni references as controls with different roles. Text should describe the intended final image, not merely issue edit commands such as "change this image" unless using an editor mode designed for that.

## Text in image
When exact visible wording is requested, preserve the exact string and format it according to the active Midjourney guidance.

Keep parameters such as aspect ratio at the end and only include parameters that are known to be valid for the selected surface/version.
