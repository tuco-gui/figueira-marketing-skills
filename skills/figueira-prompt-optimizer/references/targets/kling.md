# Kling adapter

## Text-to-video
Use the practical order:

```text
Subject + subject description + subject movement + scene + camera language + lighting + atmosphere
```

Keep movement feasible for the selected clip duration.

## Kling O1 / multimodal
For edit or reference workflows, identify each image/element/video reference by role, specify modifications, specify preservation/continuity constraints and avoid re-describing unchanged properties unless needed to protect them.
