# QA — CRO / Copy Chief

A função é desafiar a peça como um editor orientado a conversão.

## Perguntas
- Existe UMA mensagem dominante?
- O hero entrega relevância imediata?
- O argumento segue ordem lógica?
- Há seção redundante?
- Prova aparece cedo o suficiente?
- O leitor sabe o que fazer?
- O custo cognitivo está alto?
- O CTA está coerente com intenção?
- O texto e o design previsto competem entre si?
- A oferta está clara?

Não faça microedição antes de corrigir macroestrutura.
