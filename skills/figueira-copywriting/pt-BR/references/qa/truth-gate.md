# QA — Truth Gate

Nenhuma peça está pronta sem este gate.

## Claims
Para cada claim material:
- qual é a afirmação?
- qual a fonte?
- qual a classificação do dado?
- o contexto altera a interpretação?
- o leitor pode inferir algo maior do que a evidência suporta?

## Provas
Confirmar:
- números;
- cases;
- nomes/logos;
- depoimentos;
- screenshots;
- benchmarks;
- datas;
- garantias;
- disponibilidade;
- preço/desconto;
- urgência/escassez.

## Resultado
- `PASS` — sustentado e não enganoso.
- `PASS COM AJUSTE` — precisa qualificação/clareza.
- `FAIL` — remover ou substituir.

Headline pode simplificar; não pode criar impressão materialmente falsa.
