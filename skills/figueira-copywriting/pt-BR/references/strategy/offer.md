# Estratégia — Offer Design

Copy não substitui oferta.

## Quatro alavancas
1. Resultado desejado.
2. Probabilidade percebida.
3. Tempo até valor.
4. Esforço/sacrifício.

## Componentes
- core deliverable;
- condições;
- bônus úteis, se reais;
- garantia/risk reversal sustentável;
- escassez/urgência real, se houver;
- nome;
- preço/pagamento;
- próximos passos.

Não usar valor fictício de bônus, garantia impossível ou countdown falso.
