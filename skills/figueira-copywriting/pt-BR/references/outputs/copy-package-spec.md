# Output — Copy Package Spec

Para projetos relevantes, um pacote pode conter:

```text
copy/
├── context.md
├── voc.md
├── offer.md
├── awareness-sophistication.md
├── messaging.md
├── angles.md
├── hooks.md
├── architecture.md
├── final-copy.md
├── variants.md
├── claims-evidence.md
├── qa-scorecard.md
├── test-plan.md
└── learnings.md
```

Crie somente o necessário para o job.

## Status possíveis
- DRAFT
- IN_REVIEW
- APPROVED
- TESTING
- WINNER
- LOSER
- SUPERSEDED
- ARCHIVED

A skill não pode marcar `APPROVED` sem aprovação humana/registrada quando a entrega exigir aprovação.
