# Modo — Ad Copy

Cada anúncio deve ter:
- público/segmento;
- estágio de consciência;
- objetivo;
- plataforma;
- destino;
- ângulo;
- hook;
- mensagem;
- prova quando disponível;
- CTA;
- message match com a próxima etapa.

## Matriz de ângulos
Crie variações por ângulo, não só por palavras:
- dor;
- desejo;
- contraste;
- mecanismo;
- prova;
- demonstração;
- objeção;
- história;
- oportunidade;
- custo da inação.

Para teste, altere preferencialmente uma variável estratégica por vez.
