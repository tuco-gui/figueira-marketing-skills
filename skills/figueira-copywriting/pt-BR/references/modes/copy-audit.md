# Modo — Copy Audit

Audite antes de reescrever.

## Diagnóstico
Para cada problema, registrar:
- elemento;
- falha;
- impacto provável;
- evidência/razão;
- prioridade;
- correção recomendada.

## Dimensões
- clareza;
- relevância;
- message match;
- valor;
- diferenciação;
- prova;
- objeções;
- magnetismo;
- ritmo;
- CTA;
- confiança;
- compliance;
- CRO.

Não declarar causalidade de conversão sem dados. Use `HIPÓTESE` quando apropriado.
