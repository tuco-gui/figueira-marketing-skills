# Modo — VSL

Priorize a voz do narrador como artefato principal.

Estrutura adaptável:
Hook → problema/desejo → história/contexto → mecanismo → solução → prova → oferta → objeções → risco → CTA.

Direções visuais devem ser mínimas e apenas quando:
- claim precisa aparecer na tela;
- asset específico é obrigatório;
- timing visual é parte da persuasão;
- demonstração do produto é necessária.

Não sobrecarregue o editor com instruções em cada frase.
