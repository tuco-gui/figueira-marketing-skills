# Testing — Learning Log

O aprendizado deve sobreviver à campanha.

Para cada teste:
- contexto;
- hipótese;
- variante A/B;
- resultado;
- qualidade do dado;
- interpretação;
- o que aprendemos sobre público/oferta/mensagem;
- próximo teste.

Separar:
- resultado observado;
- explicação provável;
- decisão operacional.
