# Output — Copy Package Spec

For relevant projects, a package may contain:

```text
copy/
├── context.md
├── voc.md
├── offer.md
├── awareness-sophistication.md
├── messaging.md
├── angles.md
├── hooks.md
├── architecture.md
├── final-copy.md
├── variants.md
├── claims-evidence.md
├── qa-scorecard.md
├── test-plan.md
└── learnings.md
```

Create only what the job needs.

## Possible statuses
- DRAFT
- IN_REVIEW
- APPROVED
- TESTING
- WINNER
- LOSER
- SUPERSEDED
- ARCHIVED

The skill cannot mark something `APPROVED` without recorded human approval when the deliverable requires it.
