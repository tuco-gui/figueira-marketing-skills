# Persuasion — Urgency & Scarcity

Legitimate urgency:
- a real date;
- a real window;
- a condition that is changing;
- limited operational capacity;
- a real batch/stock limit;
- a real schedule;
- a real event.

Legitimate scarcity:
- an actually limited quantity;
- capacity-limited spots;
- physical availability;
- genuinely restricted access.

Prohibited:
- a resettable countdown;
- a permanent "last 3 spots";
- fictitious stock;
- an invented deadline;
- an artificial threat.
