# QA — Truth Gate

No piece is done without this gate.

## Claims
For each material claim:
- what is the statement?
- what is the source?
- how is the data classified?
- does context change the interpretation?
- can the reader infer something larger than the evidence supports?

## Proof
Confirm:
- numbers;
- case studies;
- names/logos;
- testimonials;
- screenshots;
- benchmarks;
- dates;
- guarantees;
- availability;
- price/discount;
- urgency/scarcity.

## Result
- `PASS` — supported and not misleading.
- `PASS WITH ADJUSTMENT` — needs qualification/clarity.
- `FAIL` — remove or replace.

A headline can simplify; it cannot create a materially false impression.
