# Mode — Landing Page

Goal: build a complete argument for one primary action.

## Minimum context
- traffic source;
- prior campaign/keyword/angle;
- audience;
- offer;
- CTA;
- proof;
- objections;
- constraints.

## Adaptable standard structure
1. Hero: promise/value + specificity + CTA.
2. Message match: confirm the visitor landed in the right place.
3. Problem/desire: make the situation recognizable.
4. Solution/mechanism: explain the alternative.
5. Benefits/outcomes: So What Chain.
6. Proof: case studies, data, demonstrations, verifiable authority.
7. How it works: reduce perceived complexity.
8. Objections: FAQ, comparisons, risk.
9. Offer: what they get, conditions, next steps.
10. Final CTA: a clear decision.

Don't force every landing page to have exactly these sections. Remove whatever doesn't serve the job.

Integration: after the text architecture is set, the design and web implementation team/skill defines UX/UI and runs the visual browser QA.
