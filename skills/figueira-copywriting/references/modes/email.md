# Mode — Email

Define the email's function:
- acquisition;
- nurture;
- activation;
- promotion;
- win-back;
- retention;
- reactivation;
- transactional with a commercial opportunity.

## Structure
Subject → preview → opening → argument → proof/objection → CTA.

Emails in a sequence should each have a specific role; don't repeat the same pitch with synonyms.

A magnetic subject line can't promise something the body doesn't deliver.
