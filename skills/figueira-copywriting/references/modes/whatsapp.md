# Mode — WhatsApp

Copy should sound human, contextual and useful.

## Principles
- acknowledge existing context;
- keep the message short when possible;
- one main intent;
- language natural to the recipient;
- reduce friction to reply;
- use questions that are easy to answer;
- cadence proportional to the relationship.

Do not pretend to be a specific person when the message is automated, if that creates a deceptive impression.

For collections/billing, legal, health, or other sensitive contexts, apply the project's specific rules and compliance requirements.
