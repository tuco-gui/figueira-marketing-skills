# Mode — Copy Audit

Audit before rewriting.

## Diagnosis
For each problem, record:
- element;
- failure;
- likely impact;
- evidence/reasoning;
- priority;
- recommended fix.

## Dimensions
- clarity;
- relevance;
- message match;
- value;
- differentiation;
- proof;
- objections;
- magnetism;
- rhythm;
- CTA;
- trust;
- compliance;
- CRO.

Do not claim conversion causality without data. Use `HYPOTHESIS` when appropriate.
