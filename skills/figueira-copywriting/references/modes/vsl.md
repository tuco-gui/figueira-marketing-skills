# Mode — VSL

Prioritize the narrator's voice as the primary artifact.

Adaptable structure:
Hook → problem/desire → story/context → mechanism → solution → proof → offer → objections → risk → CTA.

Visual directions should be minimal, and used only when:
- a claim needs to appear on screen;
- a specific asset is mandatory;
- visual timing is part of the persuasion;
- a product demonstration is necessary.

Don't overload the editor with instructions on every single sentence.
