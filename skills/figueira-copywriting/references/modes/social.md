# Mode — Social

Possible objectives:
- attention;
- authority;
- education;
- identification;
- proof;
- community;
- demand;
- conversion.

Adaptable structure:
Hook → context → tension/insight → value → payoff → CTA.

The CTA can be a comment, save, share, DM, click, or purchase — pick one priority.

Don't turn every post into an ad.
