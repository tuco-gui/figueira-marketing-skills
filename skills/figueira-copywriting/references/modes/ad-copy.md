# Mode — Ad Copy

Every ad should have:
- audience/segment;
- awareness stage;
- objective;
- platform;
- destination;
- angle;
- hook;
- message;
- proof when available;
- CTA;
- message match with the next step.

## Angle matrix
Create variations by angle, not just by wording:
- pain;
- desire;
- contrast;
- mechanism;
- proof;
- demonstration;
- objection;
- story;
- opportunity;
- cost of inaction.

For testing, preferably change one strategic variable at a time.
