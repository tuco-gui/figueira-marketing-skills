# Mode — Sales Page

Use for long-form direct-sale pages.

## Priorities
- a strong, sustainable central promise;
- emotional + logical progression;
- mechanism;
- abundant, verifiable proof;
- objections;
- offer and risk reversal;
- a repeated CTA with context, not spam.

## Possible progression
Hook → identification → cost of the situation → new possibility → mechanism → demonstration → proof → offer → objections → risk → decision.

Use open loops only if there's a real payoff.

In consultative high-ticket, the CTA can be an application/diagnostic rather than an immediate purchase.
