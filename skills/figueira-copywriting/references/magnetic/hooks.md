# Magnetic — Hooks

Hook = a promise of attention, not a promise of purchase.

## Types
- recognizable pain;
- specific outcome;
- question;
- contrast;
- data/proof;
- observation that runs against common sense;
- story;
- demonstration;
- common mistake;
- mechanism;
- objection;
- opportunity.

## QA
A strong hook must:
- select the relevant audience;
- be quickly understandable;
- create a reason to keep going;
- deliver the payoff afterward.

High CTR with the wrong audience is a false positive.
