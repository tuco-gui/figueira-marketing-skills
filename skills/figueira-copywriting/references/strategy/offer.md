# Strategy — Offer Design

Copy does not replace the offer.

## Four levers
1. Desired outcome.
2. Perceived likelihood.
3. Time to value.
4. Effort/sacrifice.

## Components
- core deliverable;
- conditions;
- useful bonuses, if real;
- sustainable guarantee/risk reversal;
- real scarcity/urgency, if any;
- name;
- price/payment;
- next steps.

Do not use fictitious bonus value, an impossible guarantee, or a fake countdown.
