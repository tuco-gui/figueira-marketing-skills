# Creative routing
Use this skill when designing websites, UI motion, explainer videos or procedural artwork. Read the relevant upstream README and SKILL.md before use. Do not execute unreviewed third-party scripts. Pin a reviewed revision before installation; preserve upstream license and asset restrictions. Never expose credentials or customer data to an external service without authorization.
## Design references
- https://tabbied.com — editable site templates and patterns; verify the template's commercial terms before use.
- https://landdding.com — visual research by color; use as inspiration, not as permission to copy third-party designs.
- https://github.com/LottieFiles/motion-design-skill — UI motion guidance; use alongside existing web design skills, respect reduced motion and performance.

## Execution policy
GitHub is the reference store, not a renderer. Read this file via repository connector or HTTPS when native skills are unavailable. Coding agents may use native skill discovery or a reviewed local checkout. Prefer current sandbox or existing authorized rendering service; do not provision servers or use GitHub Actions by default. For text-only agents, return a storyboard or handoff to an authorized executor rather than claim a render. Verify output dimensions, audio sync, brand consistency, accessibility, rights and actual file availability before delivery. Do not use a paid generation API without explicit budget approval. Never report installation or execution without evidence.

## Figueira — padrão obrigatório de landing pages (28/11/2026)
- CTAs sem setas decorativas/indicativas, com texto centralizado em todos os botões; dimensionar e centralizar botões no contexto da seção. Usar contraste cromático conforme paleta do cliente e legibilidade, validando contraste WCAG AA (4,5:1 para texto comum; 3:1 para texto grande e controles). Não usar apenas cor para comunicar estado.
- Centralizar itens de faixas de destaque, rótulos e flat icons em cards; manter consistência de espaçamento e hierarquia visual.
- Plantas, galerias e imagens: aproveitar largura disponível, preservar proporção e legibilidade original; ampliar em modal centralizado no viewport atual, sem saltar a rolagem, com fechamento acessível.
- Usar somente logotipos oficiais aprovados pelo cliente, variante adequada ao fundo, sem deformação; marca azul Realize sempre sobre branco. Rodapé com assinatura textual ‘Feito pela Figueira Marketing’ e link institucional.
- Pré-cadastros: preferir opções selecionáveis em perguntas de múltipla escolha; confirmar persistência e protocolo antes de abrir WhatsApp, nunca confundir abertura com envio. QA desktop/mobile e teste real de integração isolado antes de dizer concluído; sem campanhas antes de homologação.
