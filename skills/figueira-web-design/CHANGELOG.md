# Changelog — figueira-web-design

## [0.1.0] - 2026-08-30

### Added
- Web design orchestration across nine gates: context, design thesis, references, design system, architecture/wireframe, pre-code critique, implementation, browser review and final QA.
- Four experience modes: `landing-page`, `ecommerce`, `website`, `webapp` (`references/modes/`).
- Four technical adapters: `wordpress-woocommerce`, `shopify`, `react-nextjs`, `generic-web` (`references/adapters/`).
- QA references: anti-AI-slop, design critique and final scorecard (`references/qa/`).
- Adoption gate for external components (21st.dev, shadcn/ui, Magic UI, Aceternity UI, React Bits) covering job fit, coherence, stack, dependencies, performance, accessibility, license and maintainability (`references/component-sources.md`).
- Routing guidance for auxiliary visual skills (`references/tool-routing.md`).
- Evaluation suite in `evals/rubric.md` and `evals/cases.md`.
- Codex UI metadata (`agents/openai.yaml`).
- Complete Portuguese (pt-BR) translation mirroring the English tree.

### Notes
- First public release, extracted and sanitized from an internal draft. References to a specific agency's methodology, internal knowledge base, agents and governance were removed or generalized for use by any organization.
