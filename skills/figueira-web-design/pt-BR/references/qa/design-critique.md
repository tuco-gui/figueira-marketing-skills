# QA — Crítica de Design

Execute a crítica através de cinco lentes.

## 1. Estratégia
- o job principal está evidente?
- a hierarquia favorece a ação certa?
- design e conteúdo servem ao mesmo argumento?

## 2. Identidade
- parece aquela marca?
- há decisões específicas do setor/assunto?
- a expressão visual é coerente com o posicionamento?

## 3. Composição
- existe ritmo?
- o contraste entre seções é intencional?
- os alinhamentos são consistentes?
- whitespace e densidade ajudam a leitura?

## 4. Interface
- os estados estão claros?
- as ações parecem ações?
- componentes similares se comportam do mesmo jeito?
- o mobile preserva a prioridade?

## 5. Craft
- a tipografia é refinada?
- as imagens têm tratamento consistente?
- os detalhes estão alinhados?
- o motion tem uma função?
- há elementos que poderiam ser removidos sem perda?

## Saída

Liste no máximo:
- 3 problemas críticos;
- 5 melhorias relevantes;
- 3 elementos fortes que devem ser preservados.

Priorize impacto, não quantidade de comentários.
