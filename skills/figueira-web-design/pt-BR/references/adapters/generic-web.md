# Adapter — Generic Web

Use quando nenhum adapter específico se aplica.

## Princípios

- HTML semântico;
- CSS organizado por tokens e componentes;
- JavaScript progressivo;
- acessibilidade;
- responsividade;
- SEO quando público/indexável;
- dependências mínimas;
- conteúdo real;
- performance.

Não escolha um framework só para estilizar uma página simples.
