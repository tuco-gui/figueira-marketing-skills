# Phase: Equity audit (mandatory in rebrand)

## Objective
Identify what already has recognition and trust value in the current brand, so the rebrand deliberately decides what to preserve and what to discard — instead of losing equity by accident.

## What brand equity is (for this skill)
Any element the audience already reliably and positively associates with the brand: name, symbol/logo, proprietary color(s), distinctive typography, recognizable tone of voice, tagline, mascot/character, graphic pattern, or even a consistent behavior/promise ("this brand always delivers fast").

Equity is not "what leadership likes" — it's what the **market** already recognizes and associates with the brand.

## Process
1. **Inventory current elements** — list name, logo, palette, typography, tone of voice, tagline and any recurring visual/verbal assets, with evidence of where they appear (site, packaging, materials).
2. **Classify each element by recognition strength**:
   - `STRONG EQUITY` — clear recognition and positive association (evidence: length of use, consistent presence, real feedback if any).
   - `WEAK EQUITY` — present but not very distinctive or not very consistent.
   - `NO EQUITY` — element hasn't had enough time, consistency or visibility to generate recognition.
   - `NEGATIVE EQUITY` — element actively associated with something the rebrand is trying to fix (a common reason for a rebrand).
3. **Decide per element**: preserve / evolve / discard — with an explicit rationale tied to the classification above and to the brand problem from Gate 1.
4. **Record what must not be destroyed** — carry this list into Gate 3 (strategy) as an explicit constraint, not a suggestion.

## Truth rule
Without real recall/recognition research, the equity-strength classification is a `HYPOTHESIS` grounded in observable evidence (time in market, consistency of use, presence across touchpoints) — never present it as `VERIFIED FACT` unless there is real data (brand research, name-search analytics, etc.).

## Common mistake to avoid
Treating "leadership is tired of the current logo" as equivalent to "the current logo has no equity." Internal fatigue is a discovery signal, not a substitute for assessing external recognition.
