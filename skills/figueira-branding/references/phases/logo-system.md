# Phase: Identity/logo system (Gate 8)

## Objective
Turn the visual territory chosen in Gate 7 into a functional logo and identity system — not a single art piece, but a system that needs to work across different contexts and scales.

## What to compose
1. **Primary logo** — main, complete version (symbol + logotype, if both exist).
2. **Necessary variations** — horizontal/vertical/symbol-only/logotype-only — only the ones the business will actually use (don't generate variations "because everyone has them").
3. **Clear space and minimum size** — clear rules for free space and legibility at small sizes (favicon, social avatar).
4. **Color versions** — full color, monochrome, negative (dark background) — tested against real brand backgrounds, not just a white presentation background.
5. **What not to do with the logo** — 3-5 common misuse examples, specific to this brand (not a generic list copied from another guideline).
6. **Final palette** — primary, secondary and support colors, with codes (hex/RGB/CMYK/Pantone when applicable) and a rationale for each one's use.
7. **Final typographic system** — primary and secondary family, usage hierarchy, fallback for when the licensed font isn't available.
8. **Final graphic elements** — patterns, icons, textures that make up the system.

## System test (not single-piece test)
Before closing, apply the logo in at least 3 real, distinct contexts (e.g., 16px favicon, email signature, storefront/packaging) — a logo that only works at presentation size is not a ready system.

## Common mistake to avoid
Endlessly polishing the primary logo version while ignoring whether the system holds up in the business's real usage contexts (Gate 9 covers this in more depth with applications).

## Output of this gate
Logo system + palette + final typography, ready to be tested in real applications in Gate 9.
