# Mode: new-brand

## When to use
New brand, new product, company with no existing brand system. There is no equity to preserve and no declared identity to compare against — the work starts from zero, but that does not exempt it from strategy.

## What changes in the default workflow
- Gate 0 (context): there is no "lived" identity to audit. Focus on gathering facts about the business, the audience and the category — do not invent history.
- Gate 2 (research): heavier weight on category, competition and saturated visual/verbal codes, because there is no existing baggage to protect.
- There is no equity-audit gate — go straight from research to strategy/positioning.
- Naming (Gate 4) is frequently needed here, unlike refresh/extension.

## Risks specific to this mode
- Rushing straight to logo/palette because "it's all new anyway" — the absence of equity is not a license to skip strategy; it's the opposite, because nothing is holding the brand together if the strategy fails.
- Ambition disproportionate to the business's real stage (promising a "leader" identity for a pre-launch company).
- Naming without basic legal verification before moving forward with visual identity around it.

## Minimum deliverable (LEAN)
One-page positioning + one developed visual territory + essential applications (logo, color, typography, 2-3 real touchpoints of the business).

## Standard deliverable (STANDARD/DEEP)
Follows the full Gate 0-12 workflow from `SKILL.md`.
