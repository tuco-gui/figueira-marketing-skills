# QA: Critique e seleção (Gate 7)

## Objetivo
Avaliar os três territórios visuais do Gate 6 com critérios explícitos, para que a escolha final seja
defensável — não "gosto mais desse" sem racional.

## Critérios de avaliação, por território
1. **Alinhamento estratégico** — o território expressa visualmente o posicionamento do Gate 3? Ou é
   bonito mas desconectado da estratégia?
2. **Diferenciação de categoria** — o território se distingue dos códigos visuais saturados identificados
   na pesquisa (`research.md`)? Ou repete o que a categoria já faz?
3. **Distinção entre os três territórios** — aplicar o teste de genuinidade de `visual-territories.md`.
4. **Resistência ao anti-ai-slop** — checar contra `anti-ai-slop.md`.
5. **Viabilidade de sistema** — o conceito aguenta virar um sistema de logo/identidade completo (Gate 8),
   ou é uma ideia que só funciona como peça única?
6. **Durabilidade** — o território tem fôlego para durar, ou depende de uma estética passageira que vai
   datar rápido?
7. **Prova/rastreabilidade** — as decisões de cor/tipografia/composição têm racional registrado, ou foram
   escolhas arbitrárias?

## Formato de saída
Para cada território: nota qualitativa por critério (não precisa ser numérica) + veredito final
(avançar/descartar/combinar elementos com outro território). Se a decisão for combinar elementos de dois
territórios, documente explicitamente o que foi absorvido de cada um — não apresente a combinação como se
fosse um quarto território surgido do nada.

## Quem decide
A skill apresenta a análise comparativa; a escolha final do território (ou combinação) precisa de
validação do responsável antes de avançar para o Gate 8 — territórios visuais não são um item da lista de
aprovação obrigatória do `SKILL.md`, mas travar aqui evita retrabalho caro nos gates seguintes.

## Saída deste gate
Um território (ou combinação documentada) selecionado, com racional registrado, pronto para o Gate 8.
