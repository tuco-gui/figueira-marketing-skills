# Modo: new-brand

## Quando usar
Marca nova, produto novo, empresa sem sistema de marca existente. Não há equity para preservar nem
identidade declarada para comparar — o trabalho começa do zero, mas isso não dispensa estratégia.

## O que muda no workflow padrão
- Gate 0 (contexto): não há identidade "vivida" para auditar. Foque em coletar fatos do negócio, da
  audiência e da categoria — não invente histórico.
- Gate 2 (pesquisa): peso maior em categoria, concorrência e códigos visuais/verbais saturados, porque
  não há bagagem própria a proteger.
- Não há Gate de equity audit — pule direto de pesquisa para estratégia/posicionamento.
- Naming (Gate 4) é frequentemente necessário aqui, ao contrário de refresh/extension.

## Riscos específicos do modo
- Pressa para pular direto para logo/paleta porque "é tudo novo mesmo" — a ausência de equity não é
  licença para pular estratégia; é o contrário, porque não há nada segurando a marca se a estratégia
  falhar.
- Ambição desproporcional ao estágio real do negócio (prometer identidade de "líder" para uma empresa
  pré-lançamento).
- Naming sem verificação jurídica básica antes de avançar para identidade visual em torno dele.

## Entregável mínimo (LEAN)
Posicionamento em 1 página + 1 território visual desenvolvido + aplicações essenciais (logo, cor,
tipografia, 2-3 touchpoints reais do negócio).

## Entregável padrão (STANDARD/DEEP)
Segue o workflow completo dos Gates 0-12 do `SKILL.md`.
