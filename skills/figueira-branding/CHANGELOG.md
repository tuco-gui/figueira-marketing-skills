# Changelog — figueira-branding

All notable changes to this skill are documented here.

## [0.1.0] - 2026-08-30

### Added
- First consolidated public release, derived from an internal branding skill.
- Full 13-gate workflow (context → brand problem → research → strategy → naming → verbal identity
  → visual territories → critique → identity system → applications → brand
  guidelines/governance → final QA → handoff).
- 5 modes (`new-brand`, `rebrand`, `brand-refresh`, `brand-audit`, `identity-extension`) and 3
  depth levels (`LEAN`, `STANDARD`, `DEEP`).
- Complete `references/`: modes, phases, QA (anti-ai-slop, critique, scorecard), output spec and
  specialist routing.
- `evals/rubric.md` and `evals/cases.md` with 6 validation scenarios.
- `agents/openai.yaml` for exposure on compatible surfaces (ChatGPT/Codex/API/Atlas).

### Removed relative to internal origin
- Institutional references to a specific organization, its internal agents and its internal
  knowledge base.
