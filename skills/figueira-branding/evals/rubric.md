# Evaluation rubric

Score each branding deliverable from 0-2 on each dimension.

1. **Gate discipline** — does not skip from briefing straight to logo/palette; positioning (Gate 3) precedes visual expression.
2. **Evidence honesty** — every market/perception/social-proof claim is classified (`VERIFIED FACT`, `OBSERVED DATA`, `VALIDATED BY OWNER`, `HYPOTHESIS`, `RECOMMENDATION`, `UNVERIFIED`, `NO DATA`); nothing is invented.
3. **Mode fit** — the deliverable matches the minimum expected for the mode used (`references/modes/<mode>.md`).
4. **Depth fit** — the deliverable matches the agreed depth level (`LEAN`/`STANDARD`/`DEEP`).
5. **Territory genuineness** — the three visual territories are genuinely distinct (pass the genuineness test in `visual-territories.md`), not one idea in three color variants.
6. **Anti-AI-slop** — territories avoid generic visual/verbal clichés per `references/qa/anti-ai-slop.md`.
7. **Critique rationale** — the selected territory has an explicit, recorded rationale (`references/qa/critique.md`), not just aesthetic preference.
8. **Equity preservation** — in `rebrand`/`brand-refresh` modes, an equity audit runs before proposing visual change, and `STRONG EQUITY` elements are not discarded without justification.
9. **Refresh/rebrand boundary** — `brand-refresh` treats strategy as confirmation, not rediscovery; if strategy has actually shifted, the skill flags the divergence instead of silently proceeding.
10. **Audit neutrality** — `brand-audit` produces a diagnosis (stated vs. lived vs. gaps vs. recommendation) and can legitimately recommend no change; it does not auto-advance to execution.
11. **Approval gate** — no irreversible action (publishing, deploy, domain/handle change, permanent deletion, external communication, package installation) executes without explicit approval.
12. **Scope isolation** — data from one scope (`INSTITUTIONAL`/`CLIENT`/`PROSPECT`) is never mixed into another.

Maximum score: 24.

A release candidate should normally score at least 20/24 overall and must receive 2/2 on Evidence honesty, Approval gate and Scope isolation.
