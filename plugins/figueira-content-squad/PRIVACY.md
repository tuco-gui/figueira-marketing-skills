# Política de Privacidade — Figueira Content Squad

Última atualização: 20 de setembro de 2026.

O Figueira Content Squad é um plugin **somente de skills**. Ele não inclui servidor MCP, não mantém banco de dados próprio, não autentica usuários em serviços externos e não coleta dados por um backend da Figueira Marketing.

As skills operam sobre o conteúdo que o usuário fornece ou disponibiliza ao ChatGPT/Codex na conversa, projeto, workspace ou repositório em uso. O tratamento desse conteúdo segue os termos, controles e políticas da plataforma OpenAI e de quaisquer fontes que o próprio usuário conecte à plataforma.

A Figueira Marketing não recebe automaticamente o conteúdo das conversas do usuário pelo funcionamento deste plugin.

Não inclua segredos, credenciais ou dados pessoais desnecessários nos arquivos de contexto criados para o fluxo editorial.

Para questões relacionadas a este plugin, use o repositório público:
https://github.com/tuco-gui/figueira-marketing-skills
